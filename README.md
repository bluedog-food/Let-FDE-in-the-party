## 恋は戦だとジャンプは言った。 <br> そのFDEは婚活会場を駆け回る！ <br> 『恋に落ちやすくするFDE』

現代の戦場では電波妨害を受けたドローンをその場で改良する。
最短のリードタイムで現場を助ける彼らは Forward Deployed Engineer。
IT業界でバズワードになっているFDEという役職だ。

話は代わり、現代日本。
東京都は令和８年度に結婚支援事業『TOKYO八結び』を開催、出会いの場となる交流イベントの規模は前年度の1250人から2500人へ2倍に膨らんだ。前年度の応募倍率は約6倍で、今年度も定員を超える応募が続いているという新聞記事もある。

いままさに『かぐやさまは告らせたい』がテーマした「恋愛は戦」のような戦いが東京都の婚活会場を舞台に開幕した...のかもしれない。そんな東京に『恋に落ちやすくするFDE』が生まれないはずもなく...

タクシーアプリGoの創業者である中島宏さんが「社会課題 × マザーマーケットの大きさ」を事業検討の切り口にしていると発言されていたので、こんな話があってもいいのではないかと。日本の人口減少は日本のエンジニアが解決したいですよね。

※『恋に落ちやすくするFDE』はフィクションです。
